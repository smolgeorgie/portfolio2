FDND Programma Website

1 mei 2025 • Ilona van Oosbree

De FDND Programma Website is een open-source project voor de opleiding Frontend Design & Development aan de Hogeschool van Amsterdam. De site toont het curriculum, de semesters en de leerdoelen van de opleiding.

Open source en samenwerking

Het project is publiek op GitHub beschikbaar. Studenten en docenten kunnen bijdragen via pull requests. Dit zorgt voor een levend document dat meegroeit met de opleiding.

Toegankelijkheid als uitgangspunt

WCAG-richtlijnen stonden centraal in het ontwerp. Kleurbeheer, focusmanagement en een logische heading-structuur zijn geen afterthought maar gebakken in het ontwerp vanaf dag één.

Bekijk het project op fdnd-programma.netlify.app.
