Paer Studio: Samen bouwen aan een creatief bureau

10 maart 2025 • Ilona van Oosbree

Paer Studio is het creatieve bureau waar ik als frontend developer werk. We ontwerpen en bouwen digitale producten voor klanten die waarde hechten aan zowel esthetiek als functionaliteit.

Mijn rol

Ik was betrokken bij de bouw van de eigen studio-website: van het vertalen van het ontwerp naar werkende code, tot het optimaliseren van performance en toegankelijkheid.

Techniek

De website is gebouwd met moderne webstandaarden: semantische HTML, CSS custom properties, en een lichte laag JavaScript voor interactiviteit. Geen framework overhead; puur web platform.

Wat ik meeneem

Werken aan een "eigen" product geeft je een andere kijk op kwaliteit. Je bent tegelijk ontwerper, developer én kritische gebruiker. Dat scherpt je blik enorm.

Bekijk de live website op paerstudio.com.
